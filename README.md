# What is this?
Code used to run wispack demo for methods paper introducing wispack. 

# Version 
For the original preprint (draft 1), this code was run in the form now branched as version-1.0-preprint, with the v1.0 - Preprint Beta release of wispack.

For the published paper in NAR, this code was run as the Published_Version release (DOI below), with the v2.0 - First Production release of wispack. The version-2.0-NAR branch also contains the code as run for the final published article.
